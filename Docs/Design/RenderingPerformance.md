# 描画の最適化

## 海とモデル

- 海は257×257の連続グリッドを使う。カメラ付近を細かく、遠方を指数的に粗くし、波の幾何変位は遠方で滑らかに抑える。頂点間のUVも実際の座標から求めるため、パッチ境界やUVの継ぎ目はない。
- 海の三角形数は1,996,002から131,072へ削減。メッシュの範囲、波のCPU計算、カメラを中心に移動する方式は維持する。
- モデルは実際の描画用射影行列による視錐台と境界球で判定し、画面外なら描画命令とモデル定数更新を省略する。回転ノードの可動範囲、非均等スケールやせん断も境界に含める。
- 艦船は読み込み時に頂点クラスタリングで中・遠距離用の形状を生成する。投影された境界球の直径が200px以上なら詳細、70〜200pxなら中距離、70px未満なら遠距離を使う。UVや法線方向を区別し、小さな部品を省略する。元のFBXは変更しない。
- 同一テクスチャセットの静止メッシュを結合する。プロペラなどの回転ノードは独立させ、支点と回転を保持する。衝突やターゲット判定には元の詳細モデルの境界を使う。

## 後処理と計測

海霧とフィルム効果を1回の全画面描画で処理し、中間カラー画像とその読み書きを削除した。
海霧は積分区間を密度が有効な範囲に絞り、24点の中点積分から4点のGauss-Legendre積分へ変更した。
この区間では高さと距離の密度がそれぞれ3次式になり、その積を4点で積分できる。

GPUタイムスタンプで空、海、モデル、後処理、HUDを測る。フレーム別のクエリ領域と完了フェンスを使い、
完了済みの結果だけを読み取る。結果がまだなければ描画を優先し、計測のために待機しない。
タイトルバーのGPU時間は描画処理の時間で、Presentによる垂直同期待ちやゲーム更新のCPU時間は含まない。
F10で垂直同期を切り替えられる。対応環境では同期OFF時にtearingを許可し、リサイズ時にも同じフラグを保持する。

## 検証

Debug x64、既存の回帰テスト、シェーダーのOd/O3両構成での警告検査を実施。
追加検証は海グリッドの密度・範囲、拡大回転後の境界、視野内・背後・視野外の分類、
静止メッシュ結合とプロペラの独立性、実際の3隻のLOD削減、非同期GPU時間、リサイズを対象とする。

RX 6600 XT / 1280×720 / Debugで3隻のみを描画し、各視点で40フレームを実行、先頭9フレームを除いて計測した例：

| 視点 | モデル三角形 | モデル描画命令 | モデルGPU時間 | 全体GPU時間 |
|---|---:|---:|---:|---:|
| 近距離・詳細LOD | 651,389 | 138 | 約0.25ms | 約0.79ms |
| 中距離LOD | 291,032 | 122 | 約0.07ms | 約0.63ms |
| 遠距離LOD | 264,573 | 116 | 約0.06ms | 約0.61ms |
| 3隻とも視野外 | 0 | 0 | 約0.0002ms | 約0.50ms |

これは描画確認用シーンのGPU時間で、ゲーム全体のFPSを示す値ではない。
近距離・中距離・遠距離・背後、および各艦の両側から画像を出力して表示を確認した。
