# 機銃戦の追跡と間隔維持

敵機はプレイヤーの背後への位置取りを目指し、接近しすぎる場合は減速・回避する。
操縦はAircraftAIController、機銃の発射と命中収集はFlightSceneの敵武器更新とProjectileSystemが担当する。
機体の基本設定をaiParameters.jsonから読み、編隊生成時に以下の近距離空戦用の値を適用する。

| 設定 | 用途 | ミッションでの値 |
| --- | --- | --- |
| tailDistance | 追跡時の目標距離（m） | 1000 |
| flankDistance | 回り込みの左右幅（m） | 700 |
| disengageDistance | 接近回避・攻撃を控える基準距離（m） | 350 |
| reengageDistance | 追跡速度を上げて戻る距離（m） | 3500 |
| attackDistance | 機銃射撃の最大距離（m） | 2800 |
| aimAngleDegrees | 射撃を許可する照準角度（度） | 5 |
| aimHoldSeconds | 射撃前に照準を維持する時間（秒） | 0.12 |
| separationLookAheadSeconds | 接近回避の予測時間（秒） | 0.8 |

照準方向は相対速度と敵弾速から求めた迎撃方向を使用する。
開始猶予、射撃待ち時間、向き、距離の条件を満たした場合だけ発射する。
機銃弾は発射時に自機の速度を引き継ぎ、その後は直進する。
通常機と編隊長機の射撃間隔、敵弾速、敵弾総数の上限はCombat/mission.jsonで指定する。

左右の回り込み方向はプレイヤーの水平機首から求め、進展がない場合は左右を切り替える。
低空回復を優先し、相対速度から危険な接近を予測する。回避の保持時間は距離不足を理由に延長しない。
速度はプレイヤー速度と目標距離の誤差から調整し、機体本来の最高速度を超えない。

回帰テストでは追跡、回り込み、接近回避、低空回復、射撃猶予を確認する。
実際の飛行モデルと武器を使い、近距離追跡中の発射、敵弾上限、初期化順に依存しない射撃を検証する。
