# 中遠距離の追跡と間隔維持

基本の交戦距離は3〜6kmとし、敵は4,500mを目安に間隔を保つ。
背後への位置取りは目指すが、近距離へ回り込むことより距離帯の維持を優先する。
移動予測は最大1.5秒とし、後方60度に入るまでは機体ごとに左右2,000mの回り込みを加える。
左右はプレイヤーの機首方向から求め、12秒間進展がない場合に入れ替える。
攻撃を待機する機体も回り込みを続け、最大2機までの同時ロック制限は維持する。

3,000〜9,000mの範囲で照準が合うと、開始猶予3秒の後に2.5秒のロック予告を行う。
背後だけに攻撃を限定せず、中遠距離での横や正面からの交戦も許可する。
武器の再装填・攻撃枠・向きの条件を失うとロックをリセットする。
ミサイルの実際の発射成功をNotifyWeaponFiredで通知し、1.8秒の横離脱を作る。
離脱時間はmaximumDisengageSeconds（既定3秒）を上限とし、距離不足を理由に延長しない。
低空回復を最優先し、接近回避は相対速度から最接近を予測して判断する。
接近回避は相対速度と3.5秒先までの最接近距離で判定し、開始距離は追尾距離の1.5倍（現在6,750m）を上限とする。
危険な距離にいる間は離脱の保持時間が終わっても接近を再開しない。
後方では早めに減速し、前方・側方ではプレイヤーから離れる進路と速度を選ぶ。

速度はプレイヤー速度と後方距離の誤差から調節し、接近時や大きく向きを変えるときは減速する。
設定はAssets/Aircraft/F4U4Corsair/aiParameters.jsonに置く。

| 設定 | 用途 | 既定値 |
| --- | --- | --- |
| tailDistance | 追跡時の目標距離（m） | 4500 |
| flankDistance | 回り込みの左右幅（m） | 2000 |
| pursuitPredictionSeconds | 移動予測の上限（秒） | 1.5 |
| maximumDisengageSeconds | 横離脱の時間上限（秒） | 3 |
| repositionSeconds | 回り込み側を切り替える停滞時間（秒） | 12 |
| disengageDistance | 接近回避・攻撃を控える基準距離（m） | 3000 |
| reengageDistance | 追跡速度を上げて戻る距離（m） | 6000 |
| attackDistance | ロックできる最大距離（m） | 9000 |
| separationLookAheadSeconds | 接近回避の予測時間（秒） | 3.5 |

既存のattackSpeedは速度調節の下限、cruiseSpeedは近距離追跡の速度上限、escapeSpeedは遠距離合流の速度上限として使う。
プレイヤーが上限より速い場合はその速度に合わせるが、機体本来の最大速度は超えない。
attackRunSecondsはJSON連携の互換性のため保持し、攻撃時間だけで離脱させる判定には使用しない。
位置取りは通常の操縦入力で実現する。

速度は直前の設定の60%とし、プレイヤーの初速を390m/s、敵を507m/sとする。
最高速度はそれぞれ1,170m/sと1,248m/s、加速は285m/s²と360m/s²とする。
最低速度・揚力基準速度・失速速度・AIの速度設定も60%に合わせる。
プレイヤーはcontrolResponse=6、rollInputResponse=1.25、flightPathResponse=2.6とし、入力・傾き・進路の反応をゆっくりにする。
pitchRateRadians=0.85、turnRateRadians=1.05、yawRateRadians=0.34として旋回自体も抑える。
敵も入力応答・旋回・進路追従を緩やかにし、重さに合わせて接近回避の予測時間を広げる。
弾速、ロック予告時間、再装填時間、ダメージは維持する。
低速化に合わせ、敵ミサイルの旋回追従は8度/秒から4.8度/秒へ抑え、回避の余地を残す。

回帰テストでは設定されたプレイヤー初速（現在390m/s）で直進・旋回する目標を各120秒追跡し、実機飛行モデルの背後進入時間、
ロック開始、背後の滞在時間、発射数、遠距離滞在、離脱時間を測定する。
前方・側方・後方および実アセット初期配置から45秒以内のロック開始を要求する。
初動30秒以降の3〜6kmの滞在時間を測定し、近距離への侵入時間と遠方への逃走時間を制限する。
機体を直接移動させる距離制限ではないため、急接近や急旋回では一時的に3kmを下回る場合がある。
低空回復、反応待ち、発射通知、接近時の減速、左右反転、同時攻撃制限とリトライも検証する。
