# FlightSceneの生成と更新

本番のミッションは`FlightScene::CreateMission`で生成する。Applicationは読み込んだ定義、モデル取得関数、画面寸法、描画距離を渡す。プレイヤー、戦闘設定、武器、敵、艦船の構成順序はFlightSceneが管理する。必要なモデルが未ロードの場合や画面寸法が不正な場合は生成を失敗させ、途中のシーンをApplicationへ渡さない。

生成完了時に描画姿勢とCombatSnapshotを作り、再挑戦の基準を保存する。初回Update前に自機が削除されても基準は失われない。個別のConfigure/Add APIは、部分構成を使う回帰テスト用にも維持する。この経路では従来どおり初回更新前の状態を保存する。

## 更新順

1. フレーム通知をクリアし、有限の正の経過時間を検証する。タイマーと既存演出を進める。
2. プレイヤーと敵機を移動し、衝突判定に使う姿勢を反映する。
3. 現在の機体位置からCombatGeometryを作り、対象選択と捕捉時間を更新する。機関砲、爆弾、敵武器はここで更新し、命中を収集する。
4. 命中を時刻順に反映してからミッションを進める。自機撃墜と最後の敵撃墜が同時なら敗北を優先する。
5. 増援を含む最終姿勢を反映し、残存対象で照準を再検証する。ここでは捕捉時間を進めない。HUD向けSnapshotを一度更新し、カメラを更新する。

武器の射撃補正はCombatGeometryとTargetingSystemを参照する。HUD向けSnapshotの更新タイミングには依存しない。

## 再挑戦

終了後のR入力はFlightSceneRestart.cppのRestartに集約する。FlightScene自身のコピーや自己代入は使わず、専用のRestartStateに明示したシミュレーション状態・武器・演出・カメラを復元する。画面寸法と再挑戦データ自体は保存対象に含めない。復元後に現在の画面寸法を再適用し、表示とカメラを更新する。GPUモデルはshared_ptrで共有し、再ロードしない。

RestartStateはCreateMission完了時（部分構成では初回更新前）に一度保存する不変データである。新しく再挑戦対象の状態を追加したときは、保存と復元の両方へ明示的に追加する。構成途中のシーンを使う既存テストと、チェックポイントとしてのFlightScene値コピーは維持する。

## 責務の境界

| 担当 | 責務 |
| --- | --- |
| FlightScene | 機体と武器の更新、命中反映、各コンポーネントの実行順 |
| FlightMission | ミッション状態、増援の配置計画、艦船の登録、甲板判定、対空砲と甲板煙 |
| CombatSnapshotBuilder | 最終戦闘情報から飛行情報・未来位置照準・固定照準を作る。機体や捕捉時間は変更しない |
| FlightSceneRestart | 再挑戦に必要な状態の保存と復元 |

FlightMissionはFlightSceneへの参照やコールバックを保持しない。増援はAircraftSpawnの一覧として返し、シーンへの追加はFlightSceneが行う。モデル、機体状態、弾管理、演出などの参照は処理中の引数としてのみ使う。
