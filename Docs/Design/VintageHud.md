# 生成り色の和文HUD

参考画像のUIを基準に、文字・照準・レーダー・画面端の装飾を生成り色（#E6CDA4）で統一する。
選択中の敵は琥珀色、ミサイルのマークや被弾方向は落ち着いた朱色で区別する。
画面端には細い二重線と、毎フレーム同じ位置へ描く小さな擦れを配置する。
UI以外の3Dモデル、カメラ、海、ポストエフェクト、操縦・戦闘処理は変更しない。

1920×1080基準で速度はX=110、高度はX=1560、数値枠の上端Y=370、幅240・高さ60とする。
長方形の上に「速度」「高度」、枠内に48px基準の整数値を右寄せで表示する。
機体状態とロケット状態はレーダーの右へ置き、機体状態の下には区切り線を引く。
ロケットは「ロケット L1 使用可」「ロケット R1 2.4秒」などとし、次の発射口に三角形を添える。
既存のENEMY識別名は表示時だけ「敵機」に置き換え、内部識別子や独自の名前は維持する。

捕捉警告は上中央の「敵機接近」、ミサイル警報は「ミサイル接近」として左右に短い罫線を添える。
警告の出現条件・捕捉進行・勝敗・命中などの表示条件は既存の状態を使う。
命中予測位置と敵枠の投影も既存のまま使い、円と目盛りの意匠だけを整理する。

日本語はWindowsの「UD デジタル 教科書体 N」の標準ウェイトをGDIでアトラス化する。
参考画像の払い・止めのある筆文字へ寄せ、太い明朝体の硬さを抑える。
英数字と発射口の三角記号は読みやすい「游明朝」のDemibold相当を使う。
HudFont.hで寸法、収録文字、字送り、図形用の白い領域を共有し、TextとMeasureTextWidthは同じUTF-8解釈を使う。
日本語は固定ラベルに必要な文字を収録し、未収録の文字や不正UTF-8は「?」に置き換える。
新しい固定ラベルを追加するときはHudFont::Japaneseに必要な文字を加える。
フォント画像の拡張後も、線・塗りつぶし・エフェクトのUVは共有定義に従う。

回帰テストでは日本語と数字の混在、実際の文字幅、代替文字、右寄せ、装飾の再現性を確認する。
通常・捕捉・ミサイル・勝利・敗北の画像を800×600、1920×1080、2560×1080で出力する。
多量のエフェクトと同時に表示しても、HUDの予約頂点と全体上限に収まることを検証する。
