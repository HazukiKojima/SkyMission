# 英語のフライトHUD

レトロ化前のフライトHUDの配置と形状へ戻し、基本色は淡いクリーム色（#E8D9B5）を使う。
選択中のレーダー目標は琥珀色、被弾方向とミサイルは現在の落ち着いた朱色を使う。
海・空・3D描画・ポストエフェクトや戦闘ロジックは変更しない。

速度と高度は内側へ尖った矢印型の枠に数値を右寄せし、SPEED / ALTを添える。
1920×1080基準で数値枠の上端Y=420、幅240・高さ64とし、速度はX=100、高度はX=1580に置く。
照準は従来の同心円と12方向の目盛りへ戻す。画面外周の二重線や擦れの装飾は描かない。

固定ラベルはSPEED、ALT、HULL、LOCK、NO TARGET、OUT OF RANGE、HIT、DESTROYED、
LOCK WARNING、MISSILE ALERT、VICTORY、SHOT DOWN、R: RETRY、ALL TARGETS DOWNなどの英語に統一する。
武器はRKT L1 READY / RKT R1 2.4sなどとし、次の発射口はASCIIの > で示す。
レーダーは左下の北固定・10km範囲を維持し、北表示をNにする。

英数字はConsolasでアトラス化し、図形や文字の色・線幅・サイズ設定は現在のものを使う。
UTF-8の解析と未収録文字の代替表示は維持する。
回帰テストでは固定ラベルのASCII収録範囲、配色、速度変換・右寄せ、外周装飾の撤去を確認する。
通常・捕捉・ミサイル・勝利・敗北を800×600、1920×1080、2560×1080で描画して確認する。
