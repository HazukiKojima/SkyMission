# 敵ロックオン・20mm射撃補助・戦闘HUD

## 目的と対象範囲

敵を選択して予測照準へ機首を合わせ、20mm機関砲で撃破する。
HUDは緑の細線、角括弧の敵枠、円形の予測照準を基調とし、既存作品の画像・ロゴ・フォント素材は使用しない。
速度計、高度計、レーダー、画面遷移、爆発、効果音は対象外。カメラは現在の機体追従を維持する。

## 操作・対象選択・撃破

Fキー長押しで4門同時連射、Tab押下で対象を切り替える。
Tabは短い押下も保持し、リピートでは切り替えない。フォーカス喪失時に押下・未消費通知を解除する。
ロックしていなくても従来の前方射撃ができ、機体の自動操縦や発射後の誘導は行わない。

| 識別名 | プレイヤー初期位置を基準とする配置 |
| --- | --- |
| ENEMY 01 | (0, 300, -1200) |
| ENEMY 02 | (-450, 350, -1700) |
| ENEMY 03 | (500, 400, -2000) |

敵モデルは共有し、飛行・AI・耐久値は各敵が保持する。
耐久値100、1発10ダメージを初期値とし、0以下で敵を削除する。
選択敵を削除したら次の候補を自動選択する。再出現は行わず、全滅時にALL TARGETS DOWNを3秒表示する。
位置・耐久値・ダメージはAssets/Combat/targeting.jsonで調整する。

対象がない場合、選択距離内かつ機体前方にいる敵のうち、機首との角度が最小の敵を選ぶ。
同角度なら距離、同距離ならObjectIdの小さい順とする。
Tabでは後方の敵も含め、選択距離内の生存敵をObjectId順に巡回する。
生存・距離条件を満たす選択対象は、別の敵が近づいても自動で切り替えない。

| 設定 | 初期値 |
| --- | --- |
| 選択距離 | 6000ワールド単位 |
| 捕捉距離・角度 | 2500・機首から25度 |
| 捕捉時間 | 0.5秒 |
| 維持距離・角度 | 2750・機首から35度 |
| 条件逸脱の猶予 | 0.25秒 |
| 発射補正角度 | 3度 |

状態は対象なし、選択中、捕捉中、ロック成立。
捕捉中に条件を外れると計時をリセットする。成立後は維持条件と猶予時間でちらつきを抑える。
武器・戦闘更新は既存の飛行モデルと同じく最大0.25秒とする。

## 予測射撃と命中

銃口から対象中心への相対位置をr、対象速度から自機速度を引いた相対速度をu、弾速をsとして、
`(u・u − s²)t² + 2(r・u)t + r・r = 0` の最小の正の解を求める。
二次係数がほぼ0なら一次式として解く。解なし・正の解なし・弾寿命外は射撃解なしとする。
HUDは4銃口の平均位置、実弾は各銃口の位置から個別に計算する。
予測照準は自機速度の継承を考慮した機首の目標方向を示す。

ロック成立・現在の捕捉距離内・射撃解あり・機首との差3度以内をすべて満たす銃口だけ補正する。
条件外は機体前方のまま。初速度は `自機速度 + 発射方向 × 弾速` とし、発射後は直進する。
モデルの姿勢も補正方向へ合わせる。

モデルの正規化済みローカルAABBと敵のワールド行列をOBBとして使用する。
メッシュ単位の判定は行わず、翼間の空間も囲む近似とする。
弾の中心線の移動区間と敵の相対移動を判定し、フレーム内の敵の回転は更新後の姿勢で固定する。
寿命・海面到達までを有効区間とし、新規弾も生成時刻以降を判定する。
最初に接触した敵へ一度だけ命中して弾を消し、自機判定・貫通は行わない。
命中をイベントとして集めてから時刻順に耐久値へ反映し、走査中に敵を削除しない。
同一フレームの複数命中でも撃破通知と削除は1回とする。

## HUD・責務・描画順

機関砲照準は4銃口の平均から機首方向へ伸ばした射線の投影で、画面中央には固定しない。
生存敵に角括弧、選択敵に大きな枠・識別名・整数距離、捕捉中は進行リング、成立後はLOCKを表示する。
予測照準は円と対象への接続線、補正可能時には明るい色とする。
射撃解なしではOUT OF RANGE、後方では予測照準を消す。
画面外は選択敵だけ方向矢印を表示する。
HITは0.15秒、DESTROYEDは0.8秒。距離はワールド単位のままで、文字は英数字と記号に限定する。

TargetingSystemは対象選択、GunAimSolverは迎撃計算、ProjectileSystemは弾と命中イベント、
FlightSceneは耐久値・撃破とCombatSnapshotを担当する。
CombatControllerはF長押しとTabの押下を入力へ変換する。
CombatHudPresenterが状態を図形・文字へ変換し、HudRendererはゲームルールを持たず描画する。
永続参照にはObjectIdを使用する。

Rendererが実際に使用した未転置のビュー・射影行列と画面サイズをRenderViewで公開する。
HUDで別の遠クリップ距離や射影を計算しない。
Windows GDIで初期化時に英数字アトラスを作り、白色領域と共有して図形・文字を三角形で描く。
専用D3D12パイプラインは深度なし・アルファブレンドありとし、フレーム別の頂点バッファを初期確保する。
レトロフィルムの後、Presentの前に描画する。
1920x1080基準の均等倍率と余白で調整し、色・線幅・文字サイズはAssets/UI/combatHud.jsonに置く。

更新順は入力、機体、選択・ロック、弾と命中収集、耐久値と撃破、カメラ、3D用行列確定、HUD生成、描画。
敵枠は最終的な機体姿勢から作った位置に重ねる。

## 検証

Tab押下・リピート・フォーカス喪失、対象の巡回と消失、捕捉と猶予、迎撃の各解、3度の補正境界をテストする。
高速弾・移動/回転OBB・最初の接触・寿命/海面・多重命中と撃破・全滅後の整合を確認する。
HUDは前方・画面外・後方を投影し、800x600と1920x1080のGPU読み戻し画像で描画とリサイズを確認する。
既存の射撃・モデル・ウィンドウ操作の回帰テストも維持する。
実画面では敵枠の位置、Tab切替、捕捉、予測照準、射撃補正、撃破、文字の判読性と後処理の影響を確認する。
新規コメントの文末には「。」を付けず、文中で区切る場合のみ使用する。
