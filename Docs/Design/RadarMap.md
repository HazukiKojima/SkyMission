# 北固定のレーダーマップ

左下に暗緑色の半透明パネルを置き、自機中心・北固定の水平レーダーを表示する。
1920×1080基準で320×320px、左端と下端から48px。画面サイズに合わせて均等に縮小し、
ワイド画面でも実際の画面左下を基準にする。耐久・ロケット状態はパネルの右隣へ置く。

北はワールド−Z、画面右は−X（左は＋X）とし、中心から半径10,000mを固定縮尺で表示する。
左手座標系の北向きカメラに合わせ、自機・敵機の機首方向も同じ左右変換を使う。
高度差やカメラ姿勢では配置を変えない。5km・10kmのリングと格子を描き、北と縮尺を表示する。
地形データや索敵処理は追加せず、CombatSnapshot内の敵機と飛来ミサイルを対象にする。

自機は白い三角形、敵機は緑の機影、選択敵は黄色の角枠、ミサイルは赤い菱形で表示する。
10km外の敵は外周の方向矢印に切り替える。ミサイルも10km外では外周へ寄せる。
マークは盤面内に収め、自機は常に中心へ最後に描画する。
自機の実位置と水平機首方向をCombatSnapshotへ、敵機の水平機首方向をCombatTargetへ渡す。
銃口位置・カメラの向き・速度ベクトルで代用せず、AircraftFlightModel::GetPosition/GetHeadingを使う。

RadarMapPresenterが配置・投影・レーダー描画を担当し、CombatHudPresenterから呼び出す。
FilledRectは既存アトラスの白い領域を使い、専用テクスチャや追加シェーダーは必要としない。
投影前に非有限の座標を除外し、距離ゼロやゼロサイズ画面でもNaNや無効頂点を生成しない。

回帰テストは東西南北、5km・10km・範囲外、北固定、自機移動、実機首方向、選択と消失、
リトライ、エフェクト混在時の頂点上限を検証する。
800×600・1920×1080・2560×1080でGPU読み戻し画像を生成し、配置と判読性を確認する。
