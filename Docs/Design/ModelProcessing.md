# モデル処理の責務

モデル読み込みは、取り込み、CPU形状処理、GPUリソース生成に分ける。

| 担当 | 責務 |
| --- | --- |
| ModelImporter | Assimp設定、FBX解析キャッシュのキー・読み書き、キャッシュ不正時の元ファイル読み込み |
| ModelGeometry | ノード階層の変換、正規化、回転ノードの支点・軸、CPU頂点・索引とノード位置の生成 |
| ModelLod | CPU頂点クラスタリングによるLOD生成。UV・法線方向・接線の向きを区別する |
| Model | マテリアルとSRV、静止メッシュ結合、GPUバッファ生成・所有・描画・転送領域の解放 |

ModelGeometry.hのMeshGeometryはGPUリソースやAssimpのメッシュポインターを持たない。マテリアルはインデックスとして渡すので、CPU形状処理とLOD生成はImporterの所有期間に依存しない。AssimpのシーンとマテリアルはModel::Load内のImporterが所有し、テクスチャ設定を取り出すまで生存させる。

既存の正規化、ノード位置、LOD閾値、静止メッシュ結合、回転ノードの独立性、キャッシュ形式、GPU転送完了後の解放タイミングは維持する。
