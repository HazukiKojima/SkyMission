# プレイヤー機の20mm機関砲

## 目的・仕様

マウスの左ボタンを押している間、プレイヤー機の `GunMuzzle_L1`、`GunMuzzle_L2`、
`GunMuzzle_R1`、`GunMuzzle_R2` から4発同時に発射する。
弾は `Assets/Ammunition/20mmAmmo/20mmAmmo.fbx` を使用する。
当たり判定、ダメージ、重力、誘導、発射音、マズルフラッシュは今回の対象外。

| 項目 | 初期値・動作 |
| --- | --- |
| 発射間隔 | 0.1秒（1門あたり毎秒10発） |
| 弾速 | 機体の速度ベクトル＋機体前方×900ワールド単位/秒 |
| 寿命 | 3秒 |
| 表示全長 | 2ワールド単位。実寸ではなく調整用の仮値 |
| 同時存在数 | 最大128発。弾数自体は無制限 |
| 消滅 | 寿命到達、または弾中心が基準海面 Y <= 0 に到達 |

## 責務とインターフェース

- `Model` はメッシュを持たないノードも保持し、`FindNodePosition` と `CountNodes` で公開する。
  同名が複数ある場合、位置の取得は空値を返す。
- `ModelLoadOptions::origin` は従来の地面合わせが既定。弾は `BoundsCenter` を使用する。
- `RawInputState` は左右ボタンをデバイス別に保持し、フォーカス喪失・切断で解除する。
  `WeaponController` はスナップショットを `WeaponInput { fire }` に変換する。
- `AircraftGun` は設定・4つの銃口位置・クールダウンを保持する。発射予定時刻からフレーム末までの
  経過秒数を発射要求として返す。移動・描画は扱わない。
- `ProjectileSystem` は位置・速度・残り寿命・ObjectIdを管理する。全弾で同じModelを共有する。
- `FlightScene` が飛行更新、既存弾更新、発射、新規弾の途中経過、描画状態反映を統括する。
- `AircraftFlightModel::GetVelocity()` は機体の実速度を返す。発射処理は飛行物理に混ぜない。
- `Renderer::ReserveModelCapacity()` により、初期化時に既存オブジェクト数＋上限分の定数バッファを確保する。

## 座標とアセット

ノードの原点にAssimpの左手座標変換と親階層の累積変換を適用し、メッシュと同じ正規化を行う。
正規化範囲の計算対象はメッシュだけとし、銃口の追加によって機体サイズが変わらないようにする。

`ワールド銃口位置 = 正規化済み銃口位置 × 機体の描画ワールド行列`

描画ワールド行列には機体の `visualScale` を含む。銃口の回転は使用せず機体前方へ発射する。
弾モデルは中心合わせを行い、設定したモデル前方軸を機体の -Z 前方へ補正してから発射時の姿勢を適用する。
弾の位置・姿勢は発射後に機体から独立する。

プレイヤー機のJSONの `weapon` から `weapon.json` を参照する。
4銃口の項目は固定の `muzzleL1`、`muzzleL2`、`muzzleR1`、`muzzleR2` とする。
`fireInterval`、`muzzleSpeed`、`lifetime`、`maxProjectiles` と `ammunition` の参照を持つ。
弾設定は `model`、`modelImport`、`modelForward` を持ち、前方は `+X/-X/+Y/-Y/+Z/-Z` から指定する。
表示全長はモデルインポート設定の `normalizedExtent` で調整する。

Albedo・Metallic・Normalを既存のマテリアル経路で読み込む。Roughnessは既存の代替値を使い、AO専用経路は追加しない。
モデルとテクスチャは初期化時に読み込み、発射時にファイル読み込みやGPUリソース生成を行わない。
既存FBXとテクスチャは再書き出ししない。

## 更新と境界条件

1. 同じ入力スナップショットから操縦・武器入力を生成する。
2. プレイヤー機・敵機を更新する。
3. 既存弾を移動し、寿命・海面到達で描画オブジェクトごと削除する。
4. 更新後の機体位置・姿勢から銃口位置と速度を求める。
5. 発射要求ごとに4発生成し、その発射時刻からフレーム末まで移動させる。
6. カメラ・機体・弾の描画状態を反映する。

発射可能なら押下時に即時発射する。発射時刻は半開区間 `[0, dt)` として境界の二重発射を防ぐ。
離している間もクールダウンを進め、押し直しで連射間隔を回避できないようにする。
低FPSでも発射時刻の余りを保持する。同一フレームの銃口位置・姿勢は共通とし、軌跡補間は行わない。
更新時間は最大0.25秒、負値・非有限値・ゼロでは更新しない。

空きが4発未満なら斉射全体をスキップし、要求は持ち越さない。
設定が極端に短い発射間隔でも要求配列は同時存在数/4までに制限する。
プレイヤー不在なら新規発射を止め、既存弾は更新する。
SceneObjectの永続参照にポインタは使わずObjectIdを使う。

## エラーと検証

発射間隔・弾速・寿命・表示全長は正の有限値、上限は4以上の整数を要求する。
銃口名4個は空・重複を禁止し、モデル内でそれぞれ1個だけ存在することを初期化時に確認する。
設定エラーにはパス・項目名・理由を付け、必須モデルの失敗は初期化エラーとする。

回帰テストでは左右入力、階層ノードの座標変換と重複、連射・押し直し・低FPS、速度継承、
寿命・海面・上限、設定不正、描画オブジェクトの増減とリサイズを確認する。
実画面で銃口位置、ロール中の追従、先端方向、サイズ・マテリアルを確認する。
